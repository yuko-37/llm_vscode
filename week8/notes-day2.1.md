1. Суть (что это и зачем нужно?)
Суть: сделать 2D визуализацию данных из векторной бд.
Визуализация данных показывает как данные расположены относительно друг друга и можно оценить, как расположены данные из разных категорий. В LLM/AI контексте помогает оценить качество данных перед использованием.

3. Как работает (основная идея)
Идея: сделать выборку из векторной бд, уменьшить размерность векторов до 2 и показать на графике, подсвечивая разными цветами разные категории продуктов.
    состоит из:
        сhromadb client: клиент для работы с бд
        tsne: библиотека для уменьшения размерности векторов с сохранением расстояния между точками
        plotly.graph_objects Scatter: для создания графика с данными
        plotly.graph_objects Figure: для визуализации

`chromadb.PersistentClient -> dbclient
-> dbclient.get_collection -> collection
-> collection.get -> embeddings, documents, metadata
-> tsne=TSNE -> tsne object
-> tsne.fit_transform -> 2D embeddings -> [(x,y)]
-> Scatter with (x, y) and color by category -> Figure
-> Figure.show
`

3. Проверка понимания
Вопросы на собеседовании:
    Вопрос 1. Можно ли визуализировать данные векторной бд и как это сделать?
    Чтобы визуализировать данные векторной бд, можно использовать библиотеку tsne, которая позволяет изменить размерность векторов до 2 и 3, позволяя таким образом, создать 2D или 3D визуализацию.
